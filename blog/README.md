# CaneCreme Blog

Add new posts by following this pattern:

1. Copy one existing post HTML file in this folder and rename it with a short, lowercase, hyphenated slug.
2. Update the page title, meta description, canonical URL, structured data, visible article content, FAQ, related posts, and previous/next links.
3. Add the post metadata to `posts.js` so it appears on `blog/index.html`.
4. Use optimized JPG/WebP images from `Assets/` and keep images below 250 KB when possible.

Use SEO-friendly URLs such as `blog/healthy-rakhi-gifting-hampers.html`.
